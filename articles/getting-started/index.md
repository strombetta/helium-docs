# Get started

The complete Get started tutorial will create, configure, migrate, run, and onboard an official `Trombetta.SaaS` reference application.

> [!IMPORTANT]
> The official project template and coordinated consumer packages are not yet published. Do not use repository-internal projects or locally packed artifacts as a substitute for a supported release.

## Start here

- [Prerequisites](prerequisites.md) — Prepare the accepted .NET and PostgreSQL baseline.
- [Project template availability](install-template.md) — Understand what is available and what must be completed before installation instructions can be published.

## Available now

You can evaluate:

- the [supported application model](../overview/supported-application-model.md);
- the [accepted technology baseline](../overview/supported-versions.md);
- the [architecture](../overview/architecture-at-a-glance.md);
- the [current product limitations](../overview/scope-and-limitations.md).

## Planned tutorial

When the template is released, this section will provide an ordered and tested path to:

1. install the official template package;
2. create a consumer-owned application;
3. configure local development and PostgreSQL;
4. apply framework migrations;
5. run the application;
6. register and verify the first account;
7. create the first organization;
8. verify the active organization context.

The documentation will not publish those procedures until the corresponding artifacts and end-to-end verification exist.

## Next steps

Check the [prerequisites](prerequisites.md), then review [project template availability](install-template.md). Release availability will be announced through [What’s new](../whats-new/index.md).
